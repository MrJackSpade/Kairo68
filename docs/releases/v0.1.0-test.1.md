# v0.1.0-test.1

The first test build of Kairo68, for X68000 games. It is not published to Google Play.

- Runs X68000 floppy games (XDF, DIM, D88, HDM, 2HD) and SASI hard disk images (HDF).
- Skip memory check, on by default: the boot runs as fast as the device can until the game starts, and "Starting…" shows until the first picture.
- Machine settings for memory (1 to 12 MB) and CPU clock (10, 16 or 25 MHz).
- A game library with catalog titles, descriptions and artwork, from a folder of your games; archives are read in place.
- Controller, touch and on-screen keyboard controls, with researched defaults and a button mapping for every game.
- Save states, and per-game settings that override the all-games ones.

Games are not supplied. Kairo68 needs the X68000 IPL and character font from your own machine; import them in **Menu › Machine**. Both APK variants have the same features.
