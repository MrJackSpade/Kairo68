# v1.3.1-test.3

Test build of Kairo68, for X68000 games. It is not published to Google Play.

- Runs at full speed at the default 25 MHz on the RG DS, and faster at 10 and 16 MHz: the emulation is about two and a half times as fast as test.1, with the picture, sound and timing unchanged.
- The FM synthesizer runs on its own thread, and the emulator is built with a profile of real play for faster code.
- Boots and disk loads are faster.
- After a boot or fast-forward, the sound no longer plays up to a third of a second behind the picture; it catches up as soon as normal speed resumes.
- Faster native code throughout the emulator (calls inside the emulator no longer go through the symbol table).
- Tapping a save slot right after the save state page opens no longer loses the tap, and the page keeps an open Replace or Load question instead of closing it when it refreshes.
- Closing the on-screen controls arrangement page no longer crashes the app.
