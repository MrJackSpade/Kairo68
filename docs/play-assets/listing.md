## Short description

Play your X68000 games on Android with touch controls or a gamepad.

## Full description

Kairo68 lets you play your own X68000 games on Android. Add your disk images, pick a game from the library, and play with a gamepad or on-screen controls, including an X68000 keyboard. On a two-screen handheld, the game and controls can use separate displays.

Games and the X68000 BIOS aren't included. Some games need extra setup.

You can also download the same app free from Kairo68 GitHub Releases. The Play version has the same features.

Kairo68 is an independent project using MAME's X68000 emulation.
