# Google Play listing: Japanese (ja-JP)

- **App name:** Kairo68

## Short description

Android で、お手持ちの X68000 ゲームをタッチ操作やゲームパッドで遊べます。

## Full description

Kairo68 は、お手持ちの X68000 ゲームを Android で遊べるアプリです。ディスクイメージを追加してライブラリからゲームを選び、ゲームパッドまたは画面上のコントロール（X68000 キーボードを含む）で遊べます。2 画面の携帯ゲーム機では、ゲームとコントロールを別々の画面に表示できます。

ゲームと X68000 BIOS は含まれていません。一部のゲームには追加の設定が必要です。

同じアプリを Kairo68 の GitHub Releases から無料でダウンロードすることもできます。Play 版にも同じ機能があります。

Kairo68 は、MAME の X68000 エミュレーションを使った独立したプロジェクトです。
