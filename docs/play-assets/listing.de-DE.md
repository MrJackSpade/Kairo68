# Google Play listing: German (de-DE)

- **App name:** Kairo68

## Short description

Spielen Sie Ihre X68000-Spiele auf Android mit Touch-Steuerung oder Gamepad.

## Full description

Mit Kairo68 spielen Sie Ihre eigenen X68000-Spiele auf Android. Fügen Sie Ihre Datenträgerabbilder hinzu, wählen Sie ein Spiel aus der Bibliothek und spielen Sie mit einem Gamepad oder der Bildschirmsteuerung, einschließlich einer X68000-Tastatur. Auf einem Handheld mit zwei Bildschirmen lassen sich Spiel und Steuerung auf getrennte Displays verteilen.

Spiele und das X68000-BIOS sind nicht enthalten. Manche Spiele brauchen eine zusätzliche Einrichtung.

Sie können dieselbe App auch kostenlos über die GitHub Releases von Kairo68 herunterladen. Die Version bei Google Play hat dieselben Funktionen.

Kairo68 ist ein unabhängiges Projekt auf Basis der X68000-Emulation von MAME.
