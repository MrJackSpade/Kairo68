# Google Play listing: Indonesian (id)

- **App name:** Kairo68

## Short description

Mainkan game X68000 Anda di Android dengan kontrol sentuh atau gamepad.

## Full description

Kairo68 memungkinkan Anda memainkan game X68000 milik Anda sendiri di Android. Tambahkan image disk Anda, pilih game dari pustaka, lalu mainkan dengan gamepad atau kontrol di layar, termasuk keyboard X68000. Di handheld dua layar, game dan kontrol dapat ditampilkan di layar terpisah.

Game dan BIOS X68000 tidak disertakan. Beberapa game memerlukan pengaturan tambahan.

Anda juga dapat mengunduh aplikasi yang sama secara gratis dari GitHub Releases Kairo68. Versi Google Play memiliki fitur yang sama.

Kairo68 adalah proyek independen yang menggunakan emulasi X68000 dari MAME.
