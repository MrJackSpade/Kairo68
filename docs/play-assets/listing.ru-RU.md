# Google Play listing: Russian (ru-RU)

- **App name:** Kairo68

## Short description

Играйте в игры для X68000 на Android с сенсорным управлением или геймпадом.

## Full description

Kairo68 позволяет играть в ваши собственные игры для X68000 на Android. Добавьте свои образы дисков, выберите игру в библиотеке и играйте с геймпадом или с экранным управлением, включая клавиатуру X68000. На портативных устройствах с двумя экранами игру и управление можно вывести на разные экраны.

Игры и BIOS X68000 не входят в комплект. Некоторым играм нужна дополнительная настройка.

Это же приложение можно бесплатно скачать в GitHub Releases Kairo68. В версии из Google Play те же возможности.

Kairo68 — независимый проект на основе эмуляции X68000 из MAME.
